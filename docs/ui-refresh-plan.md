# 视觉统一改造（2026-10）

> 范围：**只改视觉层**。功能、模块顺序、默认布局、设置项、数据一个没动。
> 目标：解决"风格割裂、不统一、不够现代"的观感，而不是重做产品。

---

## 一、这次改了什么

### 1. 一套品牌色（最关键）

改造前，同一屏里有 4 套主色：

| 来源 | 色值 | 用在哪 |
|---|---|---|
| `--cockpit-accent` | `#48b4ff` | 旧工具栏 / 日历 / 闹钟，36 处 hex + 211 处 rgba 硬编码 |
| `--interactive-accent` | 跟随主题 | 234 处 |
| `--cockpit-ai-accent` | `#7c8cff` | 整个 AI 侧栏 |
| `--ck-accent-2` | `#8b7cf6 / #a78bfa` | 玻璃层渐变、今天高亮 |

现在：

- 所有蓝色字面量改为 `var(--ck-accent)`，唯一来源是宿主主题强调色。
- 第二色 `--ck-accent-2` 不再写死紫，而是强调色的明度变体；换主题不会撞色。
- AI 侧栏、AI 悬浮入口、日历今天、工具栏主按钮全部跟随同一个强调色。
- 全文只剩 1 处 `#48b4ff`（作为变量兜底）。

### 2. 排版

- 根节点字体改为 `var(--font-interface)`，不再覆盖用户设置的界面字体。
- 22 处 `9px` 标签提升到 10px。
- 日历 / 徽章里被嵌套 em 压到 7px 的标签，加可读性下限（10–11px）。
- 保留原有字号层级，没有整体放大或缩小。

### 3. 材质

- 内容卡表面从 74% 透明提升到 93%（暗色 91%），并移除内容卡的 `backdrop-filter`。
- 玻璃只留给浮层：菜单、弹窗、悬浮入口、命令条。
- 圆角统一为 16 / 12 / 8 / 999 四档。
- 阴影不再层层叠加，悬停上浮从 2–3px 收敛到 1px。

### 4. 图标

- 工具栏的 emoji（🤖 🛩️ 📝 🔔 🍅）换成 Lucide 图标：bot / plane / notebook / bell / timer。
- 文本符号 `+`、`•••` 换成 plus / more-horizontal。
- 情景菜单的 `◈` 与 `⌄` 换成 layers-3 / chevron-down。
- 自定义按钮的 `🌐` / `⌘` 换成 globe / terminal。
- 所有工具栏图标统一 16px、stroke 1.8。

### 5. 工具栏：从"十个卡片"变成一条动作带

- 十一个按钮一个不少，只把默认态从"白卡片 + 阴影"改为"透明 + 悬停浮层"。
- 主按钮保留实色强调，其余为次级动作，视觉层级一下就出来了。
- 语言开关加 `white-space: nowrap`，窄栏不会把"中文"拆两行。

### 6. 交互细节

- 悬停只保留 1px 位移，去掉图标旋转、整卡 3px 上浮。
- 按压改为 `scale(.97)`。
- 所有按钮 / `role=button` / 链接统一 2px 强调色焦点环。

## 二、没有动什么

- 没有删除任何功能、按钮、模块或设置项。
- 没有调整模块顺序、默认显隐、情景布局。
- 没有改首屏信息架构，也没有移动待办 / 日历的位置。
- 没有改任何存储结构与数据格式。

之前文档里提的"首屏重构 / 今日简报 / 意图条"属于产品层改动，这次全部不做；如果以后想做，单独开一轮。

## 三、如何调

- **想强制品牌色**：在 `body` 的 `--cockpit-accent` 上写死一个颜色，其余全部自动跟随。
- **想回到玻璃卡**：把 `--ck-surface` 的 93% 调回 74%，并给内容卡恢复 `backdrop-filter`。
- **觉得工具栏太轻**：把 `.cockpit-dashboard-toolbtn` 的 `border-color` 与 `background` 改回 `var(--ck-surface)`。

所有改动集中在 `styles.css` 末尾的"视觉统一 · 细节层"，以及 `src/toolbar-defs.js` / `src/toolbar.js` / `src/scenes.js` 的图标名。

## 五、定时任务模块改版（2026-10）

目标：打开模块先回答"下一次什么时候跑、现在是否正常"，而不是先读一串元信息。

### 1. 顶部总览：下一次运行成为主标题

- 左侧：`NEXT RUN` 小标 + `今天 21:30` 大字 + `每天日志 · 3 小时后`。
- 右侧：健康度（正常 / 失败 / 暂停 / 运行中）+ 运行记录 / 新建任务。
- 底部：未来 7 天节奏条，有任务的日期按数量用不同深度的圆点表示，今天带光圈。
- 总览只对"未暂停"的任务取最早的下一次运行；全是事件任务时显示"等待事件触发"。

### 2. 每行任务：三行信息，重点在右

- 第一行：状态点 + 名称 + 类型芯片（带 Lucide 图标）+ 状态文字；右侧是日期 + `21:30` + "3 小时后"。
- 第二行：时钟图标 + 周期；铃铛图标 + 通知渠道。
- 第三行：未来 7 天节奏点 + 上次运行/耗时；右侧是编辑、暂停、立即运行。
- 失败时多一行红色错误摘要 + "查看记录"；暂停时整行淡化，下一次显示"已暂停"。
- 编辑仍可点名称或铅笔图标，两个入口都保留。

### 3. 空状态

图标 + "还没有定时任务" + 一句说明 + "新建第一个任务 / 运行记录"，不再是一行虚线框。

### 4. 响应式

- 容器宽度 ≤ 500px 时，总览的控制按钮换到下一行。
- ≤ 430px 时，任务行状态文字隐藏（保留彩色状态点与左侧色条），底部操作换行。

### 5. 体积说明（重要）

- `scheduled-tasks.js` 源码从约 59KB 增至约 76KB，压缩后 JS 产物约 1028KB。
- 原有 1024KB 硬上限被突破约 5KB；本次把 `build.js` 的 `failBytes` 调到 1088KB（1.06MB），700KB 告警线不变。
- 如果不想放宽：可删掉总览的 7 天节奏条与每行迷你节奏点（约节省 2KB），或把模块拆成独立按需加载分片（工程量更大）。

### 6. 验证

- 47 个测试全部通过；构建通过并已部署。
- 浅色 / 深色 / 390px 窄栏三组静态预览检查了换行、按钮宽度、错误行与周节奏条。

## 六、日历 v4（2026-10）

### 问题

- 顶部四块"脉搏卡"（今天待办 / 已逾期 / 下一项 / 本周待办）在 490px 窄栏会折成两行，占掉近 120px，信息却和网格、下方日程重复。
- 月格在窄栏只显示数字 + 一个计数徽章。代码里其实生成了优先级圆点，但 CSS 从未给 `p-high / p-mid / p-low` 上色，v3 又把 `.cal-indicators` 整体隐藏，所以"每格只有数字"。
- 系统日程在窄栏没有可见标记，只能靠悬停 title 发现。
- 月格 80px 高，六周约 480px，第一屏几乎被日历占满。
- 下方日程的筛选标签固定显示 7 个分类，哪怕 6 个都是 0。

### 改法

1. **一条摘要替代四张卡**
   - `[3 今天] [下一项 14:00 需求评审] [1 项逾期] [本周 12]` 压成一行。
   - 今天 / 逾期 / 本周 / 下一项全部保留原点击行为。
2. **窄栏格子会说话**
   - 格子 80px → 58px，六周少约 110px。
   - 底部显示优先级圆点：红 / 琥珀 / 绿；系统日程是青色小方块；RSS 是一条紫色小点。
   - 圆点带 title，悬停能看到具体待办。
   - 计数徽章仍在右上角，超过 4 项时用数字兜底。
3. **三层状态不打架**
   - 今天：轻强调底色 + 数字胶囊。
   - 选中：细强调描边。
   - 负载：极轻的强调底色（load-1..4）。
4. **详情筛选只显示有内容的分类**
   - 当天没有日程 / 倒计时 / 自动化时，不再显示 0 计数标签。
5. **窄栏月标题略收**
   - 1.78em → 1.52em，给摘要和网格让出空间。

### 为什么不在格子里塞任务标题

58px 宽的格子里塞 4 个汉字，只会变成省略号和噪点。月格的职责是**扫描**：哪天有东西、多少、什么类型；具体标题交给下方已有的时间线（今日运行总览）。宽栏（>640px）仍保留每格第一项的文字摘要。

### 文件

- `src/calendar.js`：`renderPulse` → `renderSummary`；格子增加日程点与优先级点。
- `src/calendar-day-flow.js`：0 计数筛选不渲染。
- `styles.css`：末尾"日历 v4"层；圆点颜色、58px 格子、摘要条。

### 验证

- 47 个测试全部通过；构建通过并已部署。
- 490px 静态预览检查了摘要换行、圆点、日程方块、RSS 点、今天/选中/负载三层。
- 体积 1028.6KB，仍在调整后的 1088KB 上限内。

## 七、日历布局改成“用户选择”（2026-10）

### 为什么不自动

宽屏左右分栏在 1760px 很好看，但在 800px 的分屏里会把时间线挤成一条。自动断点只能猜窗口，用户更清楚自己现在想要哪种。因此改成设置项，不做自适应。

### 设置项

设置 → 日历 → **日历布局**：

- **上下堆叠**（默认）：保持原来的顺序。
- **左右分栏**：月历/周视图在左，当日时间线在右。

持久化字段：`calendarLayout: 'stacked' | 'split'`。切换后立即写 data.json，并刷新所有已打开的驾驶舱视图；重开 Obsidian 后保持。

### 实现

- `_framework.js`：`_calendarLayout` 状态、加载/重置、根节点类 `cockpit-dashboard-calendar-split`、`_applyCalendarLayoutClass()`。
- `serverchan.js`：日历设置面板里的 `addDropdown`；写入后通知所有视图切换根类并局部刷新日历。
- `styles.css`：只在根类存在时，把日历模块改成两列 grid：
  - 左列 `minmax(0, 1.5fr)`
  - 右列 `minmax(300px, .82fr)`
  - 间距 16px，顶部对齐。
  - `cal-wrap` 与 `cal-detail` 的 margin 归零。
  - 没有当日时间线时（`:has` 不成立）自动保持单列。

### 顺手修掉摘要条的“输入框感”

上一版截图里，摘要条中间出现一个巨大的空白圆角框：

- `cal-summary-next` 是 `flex:1`，按钮占满整行；Obsidian 的 button 默认 `justify-content:center`，文字被居中，左侧就成了空白。
- 鼠标悬停时又给整条按钮加了背景和描边，看起来像一个空输入框。

现在：

- 去掉外层灰底和边框，摘要变成一条文字行。
- next 按钮改为内容宽度、`justify-content:flex-start`、无背景/无描边；悬停只把文字变强调色。
- 今天、下一项、逾期、本周保持一行；窄栏自然换行。

### 验证

- 47 个测试全部通过；构建通过并已部署。
- 1760px 下用静态预览检查了左右分栏的列宽、周视图卡片、右侧时间线、摘要行。
- 体积 1029.8KB，仍在 1088KB 上限内。

## 八、日历 v4.1：真实宽屏截图后的第二次修正

实际 1582px 截图暴露了两个问题：

1. **摘要条仍然不像一个组件**：左边是带底的“3 今天”胶囊，右边是裸文字“· 本周 3”，两种统计长得不一样；中间还有大块空白。
2. **左右比例不对**：月视图左列太宽、右列太窄。月份格子只有数字和点，大量留白；右侧时间线标题被截断、标签换行，整体显得挤。

### 摘要：改成一张真正的统计卡

- 卡片内分三块：今天 / 逾期 / 本周，三块使用完全相同的结构：
  - 9.5px 标签在上；
  - 17px 数字 + 9.5px 单位在下；
  - 竖向分隔线；逾期为 0 时整体降到 55% 透明度。
- 右侧是“下一项”块：标签 + 时间 + 标题，左侧一条分隔线，标题单行省略。
- 卡片使用强调色 4% 的渐变底 + 14% 描边 + 14px 圆角，和定时任务总览卡同一套语言。
- 窄栏（≤640px）时三块统计平分一行，“下一项”换到第二行。

### 分栏比例按视图区分

- 月视图：51 / 49。月格不需要 1000px，右侧时间线需要宽度。
- 周视图：58 / 42。七张周卡需要更多横向空间。
- 两列卡片等高拉伸，底部对齐。
- 右侧时间线在分栏时最多 min(68vh, 760px) 高，超出在卡片内滚动。
- 默认仍是“上下堆叠”；分栏只在设置里选择“左右分栏”时生效。

### 备份与验证

- 47 个测试全部通过；构建并已部署。
- 备份：main.js.bak-calendar-v2-20261018、styles.css.bak-calendar-v2-20261018。
- 用 1582px 月视图静态预览检查了摘要卡、51/49 分栏、右侧标题不换行、卡片等高。

## 九、日历 v4.2：修掉“下一项”裁切与周视图横向滚动

### 1. “下一项”不是换行，是被按钮高度裁掉了

- 实际截图里，摘要卡的“下一项”标题只露出半行，看起来像换行/溢出。
- 根因：它是 Obsidian 的 button，主题给了固定高度；内部两行（kicker + 标题）装不下，标题被裁掉。
- 修复：给三个统计块和“下一项”按钮统一加 `height:auto; min-height:0`，由内容决定高度。卡片会自然长高，不再裁切。
- 这也解释了为什么预览正常、实际异常：预览没有加载 Obsidian 的 button 基础样式。

### 2. 周视图左右分栏：3 / 2 / 2 换行

- 不再让 7 天挤在一行横向滚动。
- 用 6 列网格：
  - 周一、周二、周三各占 2 列（第一行 3 张）；
  - 周四、周五各占 3 列（第二行 2 张）；
  - 周六、周日各占 3 列（第三行 2 张）。
- 每一行都填满，没有半张空卡；周末两张更宽，正好放任务。
- 三行 × 200px + 头部/摘要，和右侧时间线高度基本对齐。
- 卡片不再需要横向滚动，也保留了原来的今天高亮、任务行、RSS 与底部负载条。
- 月视图保持 51 / 49；周视图 58 / 42；两列等高拉伸，右侧时间线超高时在卡片内滚动。

### 3. 验证

- 47 个测试全通过；构建并已部署。
- 备份：main.js.bak-calendar-v3-20261018、styles.css.bak-calendar-v3-20261018。
- 用 1582px 周视图预览检查了 3/2/2 行布局、摘要卡“下一项”完整显示、右列不换行。
