# Cockpit Glass

与驾驶舱插件配套的轻透主题。支持 1.14 及以上桌面版的浅色、深色模式；开启“外观 → 半透明窗口”后，系统为标题栏、侧栏、标签栏和驾驶舱背景提供一体式毛玻璃。驾驶舱卡片保留半透明层次，滚动时不切换主区域底色，也不在卡片上叠加模糊滤镜。主题不覆盖宿主的强调色，插件会跟随“外观 → 强调色”变化。普通笔记与设置页保留清晰的阅读底色；窗口内弹层不再给整个工作区增加暗色遮罩。

本地安装：将 `manifest.json` 和 `theme.css` 放入库的 `.obsidian/themes/Cockpit Glass/`，然后在“设置 → 外观 → 主题”选择 **Cockpit Glass**。关闭插件中的“一体式玻璃外观”或切换回原主题，均可随时恢复原观感。

外观细节：主工作区页签组相对整条页签栏居中，当前标签用淡强调色、字重和细下缘区分；多个标签空间不足时按宿主规则收缩，堆叠标签仍保持原布局。macOS 左侧栏收起时，展开按钮避开窗口控制按钮。左侧栏采用轻透导航轨道：静态柔光、内嵌操作托盘、顶层目录标记和独立的底部库信息区；文件树原有缩进、滚动和拖拽方式保留。搜索框与工具按钮使用浅玻璃表面，悬停时以色彩和边线反馈，按下轻微收拢，过渡约为 130–180ms。浅色与深色分别调校反光强度，沿用用户的强调色与宿主窗口拖拽区域。不新增整面遮罩、重复模糊或常驻循环动画。

设置页：标题区、侧边菜单和内容区共用同一底色，滚动时的固定标题仍能遮住下方文字。独立设置窗口也使用统一底色，不依赖透明窗口类名。macOS 在主窗口失焦时会改变原生毛玻璃的材质状态，主题 CSS 无法控制该原生状态；如需打开设置时保持主窗口玻璃效果，可在“界面”中关闭“在新窗口中打开设置”。该项是宿主偏好，不随主题安装自动修改。

系统开启“减少动态效果”时，主题关闭上述位移动效与过渡；开启“减少透明度”时，工作区恢复实色底。文件拖拽、多选、重命名和键盘定位继续使用宿主的状态反馈。主题文件可以独立更新，不需要重新构建插件。
