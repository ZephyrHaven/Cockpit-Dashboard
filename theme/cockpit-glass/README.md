# Cockpit Glass

与驾驶舱插件配套的轻透主题。支持 1.14 及以上桌面版的浅色、深色模式；开启“外观 → 半透明窗口”后，系统为标题栏、侧栏、标签栏和驾驶舱背景提供一体式毛玻璃。驾驶舱卡片保留半透明层次，滚动时不切换主区域底色，也不在卡片上叠加模糊滤镜。主题不覆盖宿主的强调色，插件会跟随“外观 → 强调色”变化。普通笔记与设置页保留清晰的阅读底色；打开设置时背景仅轻微变暗。

本地安装：将 `manifest.json` 和 `theme.css` 放入库的 `.obsidian/themes/Cockpit Glass/`，然后在“设置 → 外观 → 主题”选择 **Cockpit Glass**。关闭插件中的“一体式玻璃外观”或切换回原主题，均可随时恢复原观感。
